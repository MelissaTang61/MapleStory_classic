# 新楓之谷．經典版｜練功指南

依職業、二轉分支與角色等級，快速查詢個人練功地圖、掉落物、任務歷程及組隊任務門檻。

## 功能

- 個人練功：推薦地圖、怪物、常用掉落與稀有目標
- 任務歷程：接取條件、需求道具、完整步驟與本機進度追蹤
- 裝備反向查詢：由裝備、卷軸或素材反查怪物與地圖
- 效率比較：比較怪物 EXP、HP、屬性弱點與補水成本估算
- 地圖導航：從目前城鎮顯示前往推薦地圖的傳送點順序
- 組隊任務：等級門檻與目前是否可參加
- 資料說明：版本範圍、來源與可信度標記
